title: Herdr のインストール
description: kazuph/herdr fork のビルド、インストール、動作確認。
---

kazuph/herdr fork は Homebrew または npm からインストールできます。インストール後のコマンド名は `herdr` のままです。

## インストール

公開済みバイナリを Homebrew でインストールします:

```bash
brew install kazuph/tap/herdr
```

または、scoped npm wrapper をグローバルインストールせずに実行します:

```bash
npx @kazuph/herdr --version
# または
bunx @kazuph/herdr --version
```

ローカル開発では fork をビルドして生成バイナリを配置します:

```bash
git clone https://github.com/kazuph/herdr
cd herdr
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

macOS のローカル開発インストールでは、コピー後に署名します:

```bash
codesign -s - -f ~/.local/bin/herdr
```

別名バイナリで検証する場合は、同じビルドを `herdrx` など別名でコピーします。そのバイナリは、名前に応じた独立した config、state、socket、session namespace を使います。

## 動作確認

Homebrew またはsourceからインストールしたHerdrを起動します:

```bash
herdr
```

installしないnpm経路では、package runnerを付けて起動します:

```bash
npx @kazuph/herdr
# または
bunx @kazuph/herdr
```

シェルが `herdr` を見つけられない場合は、ターミナルを再起動するか、インストール先ディレクトリが PATH に含まれているか確認してください。

## アップデート

この fork では self-update は無効です。Homebrew は `brew upgrade kazuph/tap/herdr`、npm 実行は必要なpackage versionの指定、source build は fork checkout から再ビルドしてローカルバイナリを明示的に置き換えて更新します:

```bash
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

稼働中の Herdr server/client の再起動は別操作です。新しいバイナリをビルドしただけで、実行中runtimeを暗黙に停止・置換しないでください。

## 動作要件

このソースツリーをビルドできる Rust toolchain と、対象プラットフォームの必要ライブラリが必要です。
