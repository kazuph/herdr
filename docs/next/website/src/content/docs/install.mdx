---
title: Install Herdr
description: Build, install, and verify Herdr on Linux and macOS.
---

Install the kazuph/herdr fork with Homebrew or npm. The installed command remains `herdr`.

## Install

Install the published binary with Homebrew:

```bash
brew install kazuph/tap/herdr
```

Or run the scoped npm wrapper without a global install:

```bash
npx @kazuph/herdr --version
# or
bunx @kazuph/herdr --version
```

Build the fork from source for local development:

```bash
git clone https://github.com/kazuph/herdr
cd herdr
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

On macOS local development installs, sign the binary after copying it:

```bash
codesign -s - -f ~/.local/bin/herdr
```

For alternate-binary testing, copy the same build under another name such as `herdrx`; that binary uses its own config, state, socket, and session namespace.

## Verify

Start a Homebrew or source installation:

```bash
herdr
```

For the no-install npm paths, keep the package runner in the command:

```bash
npx @kazuph/herdr
# or
bunx @kazuph/herdr
```

If your shell cannot find `herdr`, restart the terminal or check that the install directory is on your PATH.

## Update

Self-update is disabled in this fork. Update a Homebrew installation with `brew upgrade kazuph/tap/herdr`, an npm invocation by selecting the desired package version, or a source build by rebuilding and replacing the local binary explicitly:

```bash
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

Restarting a running Herdr server or client is a separate operation. Do not stop or replace the active runtime implicitly just because a new binary was built.

## Requirements

Build requirements are the Rust toolchain and the platform libraries required by this source tree.
