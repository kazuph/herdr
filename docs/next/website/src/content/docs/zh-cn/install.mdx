---
title: 安装 Herdr
description: 构建、安装并验证 kazuph/herdr fork。
---

kazuph/herdr fork 可通过 Homebrew 或 npm 安装。安装后的命令仍然是 `herdr`。

## 安装

使用 Homebrew 安装已发布的二进制:

```bash
brew install kazuph/tap/herdr
```

或者不进行全局安装，直接运行 scoped npm wrapper:

```bash
npx @kazuph/herdr --version
# 或
bunx @kazuph/herdr --version
```

本地开发时，构建 fork 并安装生成的二进制:

```bash
git clone https://github.com/kazuph/herdr
cd herdr
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

在 macOS 本地开发安装中,复制后对二进制进行签名:

```bash
codesign -s - -f ~/.local/bin/herdr
```

如果要测试 alternate binary,可以把同一个构建复制成 `herdrx` 等其他名称。该二进制会根据文件名使用独立的 config、state、socket 和 session namespace。

## 验证

启动通过 Homebrew 或 source 安装的 Herdr:

```bash
herdr
```

使用不安装的 npm 方式时,命令中保留 package runner:

```bash
npx @kazuph/herdr
# 或
bunx @kazuph/herdr
```

如果 shell 找不到 `herdr`,重启终端,或检查安装目录是否在 PATH 上。

## 更新

这个 fork 禁用 self-update。Homebrew 使用 `brew upgrade kazuph/tap/herdr` 更新；npm 执行时选择需要的 package version；source build 从 fork checkout 重新构建并显式替换本地二进制:

```bash
just build
install -m 755 target/release/herdr ~/.local/bin/herdr
```

正在运行的 Herdr server/client 重启是单独操作。不要因为构建了新二进制就隐式停止或替换正在运行的 runtime。

## 系统要求

需要能构建此源码树的 Rust toolchain,以及目标平台所需的系统库。
